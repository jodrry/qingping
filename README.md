# 清屏 QingPing

一个基于 Android 无障碍服务的本地开屏广告跳过、误触跳转拦截与按应用统计工具。

## 功能

- 监听其他应用的窗口变化，在前 6 秒内查找并点击“跳过 / 关闭广告”。
- 检测点击后短时间内跳转到浏览器、应用商店、电商 App 的行为，自动按返回键。
- 使用本地 SQLite 按应用统计开屏拦截、跳转拦截、总次数和最近时间。
- 开机广播 + 前台守护服务 + 电池优化白名单入口。
- 不申请 `INTERNET` 权限，统计与配置只保存在本机。

## 构建

- Android Studio Ladybug 或更新版本
- Gradle 8.9+
- JDK 17
- compileSdk 35 / minSdk 26 / targetSdk 34

打开工程后 Sync，安装到 Android 8.0+ 设备。

## 首次使用

1. 打开“清屏”，点击“去开启无障碍服务”。
2. 在系统“设置 → 无障碍 → 已下载的应用”中开启“清屏 · 广告拦截”。
3. Android 13+ 如果提示受限设置，在应用信息右上角选择“允许受限设置”。
4. 授予通知权限。
5. 点击“忽略电池优化”，并在厂商自启动管理中允许清屏自启动。

## 已知限制

- 无障碍服务必须由用户手动开启，应用无法自行开启。
- `SurfaceView`、视频、游戏引擎、`FLAG_SECURE` 界面没有可读控件树，无法自动点击。
- 清屏只能在广告显示后关闭，不能阻止广告加载。
- 误触跳转保护基于“点击后 1.6 秒内发生跳转”的启发式判断，可能误拦正常外链。
- 开机自启和后台保活受 Android 版本、厂商策略、用户“强行停止”影响，无法保证 100% 存活。
- `QUERY_ALL_PACKAGES` 与无障碍拦截广告不适合直接上架 Google Play，建议侧载或企业内部分发。

## 隐私

清屏不联网，不收集、不上传任何窗口内容、应用列表或统计数据。
